# Skills — make.fun

Skill yang berguna buat berburu bounty make.fun. Baca file skill yang sesuai dengan jenis bountynya SEBELUM membangun.

## Yang ada file lengkapnya di folder ini

- **make_fun_bounty_rebuild** — PALING PENTING. Cara kerja make.fun end-to-end: ATM (Amati, Tiru, Modifikasi), aturan transkrip, recorder, bundle, check, submit.
- **gamedev-router** — milih skill game yang tepat buat tiap jenis bounty game.
- **game-feel** — game feel / juice: bikin game terasa enak dimainin.
- **game-ai** — arsitektur AI musuh/NPC di game.
- **game-ui-ux** — UI/UX game: HUD, menu, layar mulai/akhir (yang paling diliat juri).
- **frontend-design** — desain tampilan web/app yang bagus.
- **verification-before-completion** — verifikasi sebelum bilang selesai.
- **webapp-testing** — ngetes web app sampai beneran jalan.
- **fastmint-fcfs** — rebutan free mint FCFS (kalau bounty berhubungan dengan mint).
- **scenario-roblox-expert** — ahli Roblox Studio + scripting.
- **roblox-studio-mcp** — kerja Roblox lewat Studio MCP.
- **threejs-game-director** — ngarahin game Three.js.
- **threejs-qa-release** — QA + rilis game Three.js.

## Yang lain — cari + pasang sendiri

- **game-docs** — dokumentasi game.
- **canvas-design** — desain kanvas / visual.
- **algorithmic-art** — seni generatif / prosedural.

- **competitive-landscape** — analisis kompetitor / pemenang.
- **research** — riset.

- **bsc-contract-audit** — audit kontrak BSC sebelum mint.
- **fps-shooter** — mekanik FPS.
- **platformer** — mekanik platformer.
- **threejs-scene-setup, threejs-gameplay-systems, threejs-game-ui-designer, threejs-materials-lighting, threejs-gltf-loading, threejs-3d-generator, threejs-audio-generator, threejs-image-generator, threejs-debug-profiler, threejs-aaa-graphics-builder** — keluarga Three.js lainnya.
